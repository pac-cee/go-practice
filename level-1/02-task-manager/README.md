# Task Manager

A command-line task management application that demonstrates working with structs, file operations, and JSON in Go.

## Concepts Covered

- Structs and methods
- JSON encoding/decoding
- File I/O operations
- Slices and arrays
- Error handling
- Time handling
- CRUD operations

## Features

- Create new tasks with title, description, and due date
- List all tasks
- Update task status
